# Blood Donation System: Simple Guide for Everyone

## 1. What this system is
This is a website that helps people and organizations work together for blood donation.

It connects:
- Donors (people who donate blood)
- Blood banks
- Hospitals

The goal is simple: make it easier to book donations, manage blood units, and respond to hospital needs.

## 2. Why this system matters
In real life, blood is often needed quickly.

This system helps by:
- Making donor appointments organized
- Helping blood banks track blood stock
- Letting hospitals request blood clearly
- Reducing confusion and delays

## 3. Who uses it
There are 3 main user types:

### Donor
A donor can:
- Register an account
- Add personal details
- Book a donation appointment
- Choose a date and time slot
- See appointment history
- Cancel appointments when needed

### Blood Bank
A blood bank user can:
- See donor appointment requests
- View donor details (contact and profile info)
- Approve, complete, or cancel appointments
- Search donors and appointments
- Manage blood inventory by blood group
- Handle hospital blood requests

### Hospital
A hospital user can:
- Request blood units from blood banks
- Track request status (pending, approved, rejected, fulfilled)

## 4. Main features in simple words

### Login and Registration
Each person signs up and logs in with their role (donor, bank, or hospital).

### Donor profile information
Donor information can include:
- Name
- Email
- Telephone number
- City
- Blood group
- Donor ID number
- Address

### Appointment booking
Donors book appointments with:
- Date
- Time slot (for example: morning or afternoon)

### Appointment management
Banks manage appointments and can:
- Approve
- Complete
- Cancel

### Inventory management
Banks track how many blood units they have by blood type.

### Request handling
Hospitals send requests for blood units. Banks review and process these requests.

## 5. Typical real-life flow
1. A donor creates an account and books an appointment.
2. The blood bank reviews and approves it.
3. Donor comes and donates blood.
4. Bank marks appointment as completed.
5. Inventory is updated.
6. A hospital asks for blood units.
7. Bank approves and fulfills the request if stock is enough.

## 6. What statuses mean

### Appointment statuses
- Pending: waiting for bank review
- Approved: accepted by bank
- Completed: donation finished
- Cancelled: appointment cancelled

### Request statuses
- Pending: waiting review
- Approved: accepted by bank
- Rejected: not accepted
- Fulfilled: completed and blood units delivered/assigned

## 7. Safety and data handling (simple explanation)
The system tries to protect user data by:
- Requiring login
- Showing pages based on user role
- Handling data through controlled operations

Important note: this is still a project system, so it should continue improving in security and privacy before real public deployment.

## 8. What someone non-technical should remember
- Donors use it to book and track donations.
- Banks use it to manage donors, appointments, and blood stock.
- Hospitals use it to request blood.
- Time slots and donor details help make coordination clearer and faster.

## 9. If something goes wrong
If a user cannot log in, cannot book, or sees missing data:
- Check if the correct role/account is being used
- Check if required profile details were filled in
- Contact the project team/admin for support

## 10. In one sentence
This application is a practical coordination tool that helps donors, blood banks, and hospitals work together to save time and support lifesaving blood availability.
